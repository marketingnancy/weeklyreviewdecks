# Localization dashboard archive

This dashboard is archived. The daily localization workflow is report-only and does not rebuild, encrypt or publish dashboard assets.

The existing dashboard files are preserved unchanged as a historical archive. Their figures are not current daily reporting data. Do not resume the old snapshot, dashboard server or static-publication workflow for scheduled reporting.

The separate private reporting source and Claude handover are maintained in [marketingnancy/localization-report-automation](https://github.com/marketingnancy/localization-report-automation). Access requires the owner's repository permission. No credentials, database, raw provider responses or fresh report exports are published in this public archive.
